DSMART CLOUD · DSC METHOD

How a DSC idea becomes committed work

Reviewed candidates wait in the Backlog. A Pillar and a Goal give the work its purpose. After approval, each Project gets the same six parts.

  • Capture
  • Alignment and approval
  • Committed project
  • Project setup
  • Execution
Backlog

Reviewed candidates for future work.

Pillar selected

One DSC Pillar, P1–P6: where the work belongs.

Goal (purpose)

The justification. Required before a Project exists.

Approval

JC approves the move from Backlog to Project.

Project

Committed work. One active per category: Engineering, Operations, Revenue, Skills.

Six parts

Claude Project + Onboard Skill, GitHub repo, Notion PARA project, local sandbox, milestones, daily tasks.
