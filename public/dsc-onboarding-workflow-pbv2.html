DSMART CLOUD · HOW WE WORK

How a DSC idea becomes a project

Reviewed candidates wait in the Backlog. A Pillar and a Goal give the work its purpose. After approval, each Project gets the same seven parts.

  • Capture
  • Alignment and approval
  • Committed project
  • Project setup
  • Research
  • Execution
Backlog

Reviewed candidates for future work.

Pillar selected

The business area the work belongs to.

Goal (purpose)

The justification: which business goal it supports. Required before a project starts.

Approval

The founder approves before any work is committed.

Project

Committed work. Only a few projects are active at a time, so each gets full focus.

Seven parts

Claude Project + Onboard Skill, GitHub repository, Notion project page, local sandbox, research library, milestones, daily tasks.

Local Sandbox

The local project folder. Claude Code edits files here, then commits and pushes them to GitHub.

Claude Custom Onboard Skill

One command sets up every new project with the same documentation set.

Research Library

One research page per project: sources, references and research notes.
